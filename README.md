# Steel Plus – Company Website

A multi-page company website developed to present **Steel Plus**, a company operating in the construction industry, with a focus on steel structures and construction projects.

The website provides information about the company, showcases completed projects through image galleries, and includes a contact page for business inquiries.

The project was developed using HTML, CSS, JavaScript, and PHP, with an emphasis on website structure, visual presentation, navigation, and user experience.

## 1. Technologies Used

| Website Structure - HTML5 |
| Styling - CSS3 |
| Interactivity - JavaScript |
| Backend Form Processing - PHP |
| Image Galleries - JavaScript, jQuery, Lightbox |
| Icons - Ionicons |
| Typography - Google Fonts |
| Maps - Google Maps Embed |
| Development Environment - Visual Studio Code |

## 2. Key Features

### Home Page

- Company introduction and general information
- Presentation of construction services
- Navigation to the main website sections
- Visual elements highlighting the company's activities

### Projects Portfolio

- Presentation of construction projects
- Image galleries showcasing completed work
- Interactive image viewing
- Organized visual presentation of project information

### About Us

- Company background and information
- Overview of business activities
- Presentation of the company's experience and expertise

### Contact Page

- Contact form for business inquiries
- Input fields for name, surname, email, phone number, and message
- Server-side form validation and processing using PHP
- Company contact information
- Social media links
- Embedded Google Maps location

**Development Status:** The contact form interface and basic PHP processing have been implemented. However, the email delivery functionality is not yet fully configured or tested. Additional server-side mail configuration is required to enable reliable email delivery.

## 4. Project Structure

The project consists of multiple HTML pages, CSS stylesheets, JavaScript functionality, PHP form processing, and website assets.

Main files include:

- `S1.html` – Home page
- `Projekti.html` – Projects portfolio
- `Onama.html` – About Us page
- `Kontakt.php` – Contact page and server-side form processing
- `kontakt.css` – Contact page styling

Additional stylesheets, scripts, and images are included in the repository.

## 5. How to Run

### Static Website

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `S1.html` in a web browser to view the home page.
4. Navigate through the available website sections.

### PHP Contact Page

The contact page requires a PHP-enabled web server.

1. Install XAMPP or another local PHP environment.
2. Copy the project folder into the server's web root directory.
3. Start the Apache web server.
4. Open the website through `localhost`.
5. Navigate to `Kontakt.php` to access the contact form.

**Note:** The PHP contact form is currently under development. Basic form processing has been implemented, but email delivery requires additional server-side configuration and testing.
